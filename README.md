# Cantica

A responsive pre-launch fashion storefront for a conceptual Nigerian womenswear brand.

## Built

- Full-bleed editorial campaign hero
- Search and collection filters
- Device-local launch bag
- Waitlist and contact flows
- Dark mode and responsive mobile navigation

## What I learned

A pre-launch store still needs to be useful before checkout exists. Clear product information, saved items and a direct launch path matter more than pretending stock and payment systems are already live.

## Challenge

Cantica is a concept brand rather than a company I run day-to-day, so the product experience had to feel believable without inventing prices, stock levels or fulfilment operations.

I built it to practise the parts of e-commerce that happen before checkout: brand direction, product discovery and launch planning.
